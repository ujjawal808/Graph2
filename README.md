## 👨‍💻 About This Repository

**Graph2** is part of my ongoing **Data Structures & Algorithms journey using Java**.

This repository focuses on understanding and implementing fundamental **Graph concepts and algorithms** rather than simply memorizing solutions.

The implementations are written from scratch to strengthen my understanding of:

- Graph representation
- Graph traversal
- Path finding
- Weighted graphs
- Minimum Spanning Trees
- Shortest path algorithms
- Priority Queues
- Algorithmic complexity
- Problem-solving patterns

The primary goal is to understand **how each algorithm works internally**, how to implement it efficiently, and where it can be applied in real-world problems.
