# 📌 About the Repository

**Graph2** is a dedicated **Data Structures & Algorithms repository in Java** focused on understanding Graphs from fundamentals to advanced algorithmic concepts.

This repository is part of my continuous DSA preparation and software engineering journey.

Rather than only solving problems, the objective is to understand:

- How graphs are represented
- How graph traversal works
- How vertices and edges are connected
- How to find paths
- How weighted graphs work
- How shortest paths are calculated
- How Minimum Spanning Trees are constructed
- How Priority Queues are used in graph algorithms
- How to analyze time and space complexity
- How graph algorithms are applied to real-world problems

The implementations are intentionally written in **core Java** so that the underlying logic of every algorithm remains clear.
