# 📚 Graph2 - Java Graph Algorithms & DSA

A collection of **Graph Data Structure and Algorithm implementations in Java**, created as part of my Data Structures & Algorithms learning journey.

This repository focuses on understanding graph representation, traversal, shortest-path algorithms, and other fundamental graph concepts using clean and beginner-friendly Java implementations.

---

## 🚀 About the Repository

Graphs are one of the most important data structures in DSA and are widely used in areas such as:

- 🌐 Computer Networks
- 🗺️ Maps & Navigation
- 🤝 Social Networks
- 🔍 Search Engines
- 🚚 Routing & Logistics
- 🧠 Artificial Intelligence

The goal of this repository is to build a strong understanding of graph algorithms through **implementation and problem-solving in Java**.

---

## 🛠️ Tech Stack

- **Language:** Java
- **Concept:** Data Structures & Algorithms
- **IDE:** VS Code
